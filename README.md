# luozijun.com

Personal website of Zijun Luo — Assistant Professor of Economics, University of Nebraska at Omaha.

Live at <https://www.luozijun.com>.

## Building

The site is a [Quarto](https://quarto.org) website. Render it with:

```bash
quarto render
```

Output goes to `docs/`, which is what gets published.
